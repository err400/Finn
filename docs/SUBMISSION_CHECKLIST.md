- [ ] Live frontend URL and public GitHub link.

## Blockers

Hosting account access, Supabase provisioning/credentials, live endpoint URLs, and actual chat export are required external actions. Free hosting has sleep/pausing/quota limits. Licensed comprehensive exchange history, real multi-user authentication/consent/retention, and general guidance-to-actual reconciliation remain beyond this prototype's completed scope.
